Matrix multiplication: the arithmetic inside the network

The network on the previous page is two matrix multiplications and nothing else. Here is what that means, one number at a time, with the same names and the same 56 weights.

Inputs

The sliders become the two inputs, scaled to 0–1: x₁ = temperature ÷ 100 and x₂ = rain ÷ 100. Together they are a matrix with 1 row and 2 columns, written x. Move the sliders and every number below recomputes. The highlighted column starts on the neuron that fires hardest and the activity that wins; tap any column to follow a different one instead, and tap it again to let go.

The cast

Five matrices, drawn to scale, one square per number. blue is the vector going in, yellow is weights the network learned, green is what comes out. Notice that each block is exactly as wide as the next one is tall: that is what lets them be multiplied in this order.

The biases b1 (1×8) and b2 (1×5) are added after each multiplication; they are rows the same width as the result. Altogether: 16 + 40 = 56 weights and 13 biases, and the network is nothing but these numbers.

1Multiply pairs, add them up

Every number a matrix multiplication produces is made the same way: take a row from the left matrix and a column from the right one, multiply the pairs, then add the products. Here is one hidden neuron, by hand. Pick any of the eight:

2Layer 1: the same thing, eight times

Lay x down the left and W1 beside it, so each x sits next to the row of W1 it multiplies. Each column of W1 is one hidden neuron. Tap a column: the pairs light up, and the sum lands in the box below it.

x 1×2  ·  W1 2×8  →  sums 1×8  → +b1, ReLU →  h 1×8

x is 1×2, W1 is 2×8, so x · W1 is 1×8: eight numbers, one per column. Add the bias row b1 to get the sums, then apply ReLU (negative becomes 0): that last row is h.

3Layer 2: eight products per cell

Now h is the vector and W2 is the matrix. Same rule, but each column has eight pairs to multiply and add. The five sums are the scores; softmax turns them into the percentages you saw on the previous page.

h 1×8  ·  W2 8×5  →  scores 1×5  → +b2, softmax →  y 1×5

h is 1×8, W2 is 8×5, so h · W2 is 1×5. Add b2, apply softmax, and the biggest of the five wins.

4The shape rule

Two matrices can only be multiplied when the inner numbers match: the columns of the left one equal the rows of the right one. The outer numbers tell you the shape of the answer. Try some shapes:

5You try it

Compute one hidden neuron by hand: multiply the two pairs, add, add the bias, then ReLU. Two decimals is close enough.

You can type the arithmetic and let the page do it: use * (or ×) to multiply, + and -, parentheses, and max(0, …) for ReLU. Enter checks.

In code

With NumPy, @ means matrix multiply. The whole network is these two lines, and every number on this page is one cell of them:

h = relu(x @ W1 + b1) # (1×2) @ (2×8) + (1×8) → (1×8) y = softmax(h @ W2 + b2) # (1×8) @ (8×5) + (1×5) → (1×5)

Training never changes these two lines. It only changes the 56 numbers inside W1 and W2 (and the 13 biases), which is why the previous page could learn the rules without anyone writing them down.
